# Finora

A free, private money tracker: quick-add transactions, budgets, savings goals, smart insights from Fin, financial calculators (SIP, EMI, FD/RD, goal, retirement, inflation, scientific) and money lessons.

Live site: https://YOUR_GITHUB_USERNAME.github.io/finora/

## Features
- Track income and expenses (including daily and monthly repeats)
- Budgets, goals, 6-month trends and personalised insights
- Advanced calculators with charts
- Works offline from `index.html`; all data stays in your browser (localStorage)

## Run locally
Open `index.html` in any browser.

## Tech
Plain HTML, CSS and JavaScript in a single file. No build step, no dependencies.
